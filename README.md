# Strawberrfy: AI & IoT Plant Analysis 🍓

An end-to-end plant analysis application that integrates hardware sensors with AI to monitor and track plant health. Developed as part of our Cloud Computing coursework, Strawberrfy leverages IoT and advanced processing techniques like Retrieval-Augmented Generation (RAG) to provide actionable insights into plant care.

### 🚀 Project Overview

The Strawberrfy architecture is built to bridge the physical plant environment with intelligent cloud analytics. It collects environmental data using IoT sensors and processes it through a sophisticated cloud-based backend.

The system incorporates a built-in search engine and a RAG (Retrieval-Augmented Generation) system to enhance data retrieval and intelligently answer queries regarding plant health and environmental metrics.

### ✨ Key Features

* **Hardware & IoT Integration:** Seamless connection with sensors to monitor crucial plant metrics.
* **AI-Driven Analytics:** Employs intelligent models to process plant data and continuously analyze health metrics.
* **Search Engine & RAG System:** Advanced technical integration allowing efficient data retrieval and contextual analysis of the collected plant data.
* **Jupyter Notebook Workflows:** Step-by-step tutorials, lab exercises, and search engine integration documented interactively via Google Colab.

### 📂 Repository Structure

This repository contains a series of Jupyter Notebooks detailing the development pipeline, including cloud computing lab exercises and search engine integrations

### 🛠️ Tech Stack

* **Language:** Python
* **Environment:** Jupyter Notebook / Google Colab
* **Cloud & AI Integration:** RAG system architecture, Search Engine deployment
* **IoT & Hardware:** Sensor array integrations for continuous plant analysis
